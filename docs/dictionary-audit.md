# Dictionary construction and coverage audit

Initial construction was completed on 2026-09-14, metadata was reviewed on 2026-09-15, and the dictionary was then expanded with a deterministic build pipeline.

## Current shipped dictionary

- EASY: 787
- HARD: 1,847
- Total valid guesses / answer candidates: 2,634
- Original baseline preserved: 1,482 words
- Added by expansion: 1,152 words
- Every entry has a non-empty embedded Japanese gloss.
- Part-of-speech metadata is shown when confidently available and is intentionally optional rather than guessed.
- EASY and HARD answer pools are disjoint; all 2,634 words are valid guesses regardless of selected difficulty.

## Baseline construction sources

- Existing game vocabulary in the preserved reference snapshot.
- `tabatkins/wordle-list` (MIT) as a validity candidate source.
- `alex1770/wordle` hidden-answer list (MIT) as a validity candidate source.
- JMdict common English subset via `scriptin/jmdict-simplified` for development-time Japanese-gloss/POS candidates (CC BY-SA 4.0 / EDRDG terms).

## Curated baseline metadata quality pass

The original reverse-JMdict generation occasionally selected an awkward secondary sense or an incorrect part of speech. The release therefore loads `dist/assets/metadata-fixes.js` after `words.js` and before `game.js`.

This correction layer:

- repairs 447 baseline entries with clearly wrong, misleading, awkward, or school-inappropriate POS/Japanese glosses;
- moves 65 obvious school/general vocabulary items from HARD to EASY;
- removes generic `word` POS labels from corrected entries;
- replaces inappropriate result-screen glosses with neutral representative meanings.

Examples include `CHEEK = 頬`, `DIRTY = 汚い／汚れた`, `ENTER = verb / 入る・入力する`, `QUEEN = 女王`, `SHEEP = 羊`, `TRASH = ごみ／捨てる`, and `WEIRD = 奇妙な／変な`.

## Expansion

The expansion is generated by `scripts/expand_dictionary.py` from pinned baseline commit `021649449f3525f4cdfa4a51f5c491c3ce75448a`. Re-running the build therefore starts from the same 1,482-word baseline rather than adding cumulatively to the last generated dictionary.

Expansion policy:

- `alex1770/wordle` hidden-answer list (MIT) is the main puzzle-suitable expansion candidate source.
- `tabatkins/wordle-list` (MIT) supplies validity for additional common guesses.
- EJDict (CC0/Public Domain) supplies direct English-to-Japanese glosses for new entries.
- EJDict's 2,000-word frequency list is used conservatively to promote new entries into EASY.
- `first20hours/google-10000-english` is used only as a non-redistributed frequency/audit signal for candidate priority; being frequent there does not by itself make a word an EASY answer.
- JMdict common data and EJDict markers supply POS where it resolves cleanly. Unresolved POS is left blank instead of guessed.
- Entries without a concise school-safe Japanese gloss are skipped.
- Obvious proper names, brands, abbreviations, slurs, explicit terms, contractions and unsuitable candidates are rejected.

The final expansion added 1,152 words. A further 685 candidates were skipped because a concise/safe direct Japanese gloss could not be obtained under the current rules. This is deliberate: coverage is expanded only when metadata quality remains defensible.

See `docs/dictionary-expansion-report.md` for generated counts and samples.

## Independent common-word coverage audit

Before expansion, the first 3,000 entries of `first20hours/google-10000-english`'s no-swear list were filtered to exactly five A-Z letters and compared against the baseline dictionary.

- Five-letter audit reference entries: 480
- Covered after baseline audit: 439
- Reviewed explicit exclusions (proper names, brands, unsuitable vocabulary): 23
- Not present in either Wordle validity source: 18
- Remaining plausible/valid candidates not added at that stage: 0

Remaining candidates: none

The expansion then added over one thousand further legitimate five-letter words. The common-word audit remains a guardrail: rejecting an ordinary five-letter word that a general player is likely to try is treated as a dictionary-quality defect even when that word is not an EASY answer.

## Invariants

The release validator evaluates the final post-correction dictionary and verifies:

- uppercase five-letter spelling;
- unique word keys;
- exact EASY/HARD classification and disjoint answer pools;
- non-empty Japanese glosses;
- optional POS without generic placeholder values;
- 2,400–3,000 total embedded words;
- required common-word coverage and required obscure HARD examples;
- representative metadata corrections and school-safe gloss checks;
- correction-asset load order;
- duplicate-letter Wordle judging;
- TIME bonuses;
- zero runtime external calls.

The expansion workflow must pass `node scripts/validate.mjs` and `git diff --check` before generated dictionary assets are committed.
